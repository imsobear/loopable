What it is

The team’s always-on agent.

People assign work in Slack, GitHub, and on a schedule. Codex and Claude finish it on a shared computer.

  • 01

    Code review

    GitHub assigns it. The agent writes the review.

  • 02

    Dig a case

    Slack asks. The agent reads the logs.

  • 03

    Monitors

    A clock or an alert. Same agent.

Run it

One computer that stays on.

A Mac in the office. App, Dispatcher, Runner.

npm install -g loopable-cli
loopable start
loopable runner --url http://<LAN-IP>:4321 --token <from Runners>
